# Walmart Sales Analysis

I used Python, pandas, and Matplotlib to analyze monthly Walmart sales
and compare total sales across stores.

## Dataset

Download `Walmart_Sales.csv` from
https://www.kaggle.com/datasets/mikhail1681/walmart-sales

The notebook expects the file at `data/Walmart_Sales.csv`.

## Key Findings

- Highest-sales month: MONTH — $AMOUNT
- Highest-sales store: STORE ID — $AMOUNT in total sales
